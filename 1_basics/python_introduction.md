# Python – Introduction

## 1. What is Python?

**Definition:**

Python is a high-level, interpreted, general-purpose programming language known for its simple and readable syntax.

Python was created by **Guido van Rossum** and was first released in **1991**.

### Understanding the definition

- **High-level language:** A programming language that is easy for humans to read and understand compared with low-level languages.
- **Interpreted language:** Python code is executed by an interpreter.
- **General-purpose language:** Python can be used for many purposes, such as web development, automation, data analysis and artificial intelligence.
- **Readable syntax:** Python code is designed to be simple and understandable.

## 2. Why do we use Python?

Python is widely used because:

1. It has simple and readable syntax.
2. It is beginner-friendly.
3. It has a large collection of libraries and frameworks.
4. It supports automation of repetitive tasks.
5. It is widely used in data science, machine learning and AI.
6. It can work with databases, files and external services.
7. It has a large developer community.

## 3. Features of Python

| Feature | Explanation |
|---|---|
| Easy to learn | Python syntax is simple and readable. |
| Interpreted | Python code is executed by an interpreter. |
| High-level | Developers do not need to manage low-level machine details for most tasks. |
| Portable | Python programs can run on different operating systems, with suitable environments. |
| Open source | Python is freely available to use and distribute. |
| Object-oriented | Python supports classes and objects. |
| Dynamically typed | Variable types do not need to be declared explicitly. |
| Extensive libraries | Python offers many reusable modules and packages. |

## 4. Where is Python used?

### 4.1 Data Engineering

Python is used to:
- Extract data from different sources.
- Transform and clean data.
- Load data into databases and data warehouses.
- Automate data pipelines.

**Example tools:** Pandas, PySpark, Apache Airflow.

### 4.2 Data Analysis

Python is used to:
- Analyze datasets.
- Calculate statistics.
- Identify patterns and trends.
- Create charts and reports.

**Example libraries:** Pandas, NumPy, Matplotlib.

### 4.3 Artificial Intelligence and Machine Learning

Python is used to:
- Train machine learning models.
- Make predictions from data.
- Build AI applications.

**Example libraries:** Scikit-learn, TensorFlow, PyTorch.

### 4.4 Web Development

Python can be used to develop the backend of websites and web applications.

**Example frameworks:** Django, Flask, FastAPI.

### 4.5 Automation

Python can automate repetitive tasks, such as:
- Reading and processing files.
- Renaming multiple files.
- Generating reports.
- Sending automated notifications.

## 5. Python vs Java

| Python | Java |
|---|---|
| Simple and concise syntax | More explicit syntax |
| Dynamically typed | Statically typed |
| Commonly executed using a Python interpreter | Compiled to bytecode and executed by the JVM |
| Uses indentation to define code blocks | Uses braces `{}` to define code blocks |
| Popular in data science and automation | Popular in enterprise applications and backend systems |

Both languages are general-purpose and object-oriented.

## 6. First Python Program

### Program

```python
print("Hello, World!")
```

### Output

```text
Hello, World!
```

### Explanation

- `print()` is a built-in Python function.
- It displays information on the screen.
- `"Hello, World!"` is a string (text).
- Parentheses `()` contain the value passed to the function.

## 7. Understanding the Python Interpreter

**Definition:**

A Python interpreter is software that executes Python code.

### How a Python program runs

1. A developer writes Python code in a file.
2. The Python interpreter processes the code.
3. The program executes.
4. The result is displayed or produced.

**Example:**

```python
print("Welcome to Python")
print(10 + 20)
```

**Output:**

```text
Welcome to Python
30
```

## 8. Python File Extension

Python source code files use the `.py` extension.

**Example:**

```text
hello.py
```

A Python file can contain one or more Python statements.

## 9. Python Comments

**Definition:**

Comments are notes written in code for humans to understand. Python ignores comments during normal execution.

### Single-line comment

```python
# This is my first Python program
print("Hello")
```

**Output:**

```text
Hello
```

The line beginning with `#` is a comment and is not executed as a Python statement.
